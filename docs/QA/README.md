## Conventions

- Keep one checklist per feature slice or workflow.
- Prefer task-focused names such as `membership-invite-testing-checklist.md`.
- Put portal flows under `docs/QA/portal`.
- Put mobile/app flows under `docs/QA/mobile`.
- If a checklist replaces an older doc elsewhere in `docs`, leave a short pointer file behind rather than silently deleting it.
